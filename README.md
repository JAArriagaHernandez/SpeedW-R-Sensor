# SpeedW-R-Sensor

> **English** | [Español](#español)

Companion code and manuscript materials for optical wavefront and phase sensing with spatial light modulators (SLMs), featuring the **SpeedW-R-Sensor** graphical user interface (GUI) for rapid processing and analysis.

Pre-built executable packages for **Windows** and **macOS** are available in the shared Google Drive folder:

## Platform Overview

The **SpeedW-R-Sensor** GUI is packaged to run directly on desktop workstations without requiring manual environment setup:

* **Windows:** Distributed as a standalone Windows executable package for direct execution on supported 64-bit Windows systems. On first launch, Windows SmartScreen may display a prompt for unsigned/research builds—select **More info** and **Run anyway** if trusted.
* **macOS:** Distributed as a macOS application bundle/archive tailored for desktop use on Apple Silicon and/or Intel Macs (depending on the build inside the folder). If macOS Gatekeeper blocks the first launch of an unnotarized build, right-click/Control-click the app and select **Open**, or allow it under **System Settings > Privacy & Security**.

La interfaz **SpeedW-R-Sensor** está empaquetada para ejecutarse en equipos de escritorio sin necesidad de configurar entornos desde cero:

* **Windows:** Se distribuye como paquete ejecutable para sistemas Windows de 64 bits. Al abrirlo por primera vez, Windows SmartScreen puede mostrar una advertencia por tratarse de un paquete de investigación/sin firma comercial; en ese caso, elige **Más información** y **Ejecutar de todas formas**.
* **macOS:** Se distribuye como aplicación/paquete para macOS pensado para uso de escritorio (según la compilación disponible en la carpeta). Si Gatekeeper bloquea la primera apertura de un ejecutable sin notarización, haz clic derecho (o `Control` + clic) sobre la aplicación y selecciona **Abrir**, o autorízala desde **Configuración del Sistema > Privacidad y seguridad**.
